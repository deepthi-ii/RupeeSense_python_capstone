# RupeeSense — Python Edition

RupeeSense is a personal finance and shared-expenses website. The backend is written in **Python using Flask**. The existing RupeeSense page design is retained in HTML templates and CSS.

## Included features

- Email/password sign-up and sign-in through Supabase Auth
- Personal income and expense transactions
- Dashboard totals for income, expenses, and net balance
- Savings goals with progress display
- Create shared rooms and invite members with a code
- Join a room using its invite code
- Add shared expenses and divide them equally between room members
- Responsive RupeeSense styling

## Run locally on Windows

1. Install Python 3.10 or newer.
2. Extract this ZIP and open PowerShell in the `rupeesense_python` folder.
3. Create and activate a virtual environment:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

4. Install the packages:

   ```powershell
   python -m pip install -r requirements.txt
   ```

5. Copy `.env.example` to a new file named `.env` and fill in your Supabase Project URL and anon/publishable key. Create your own long random `FLASK_SECRET_KEY`.
6. Start the website:

   ```powershell
   python app.py
   ```

7. Open `http://127.0.0.1:5000` in your browser.

## Supabase configuration

This edition uses the Supabase project already associated with your RupeeSense website. Configure `SUPABASE_URL` and `SUPABASE_ANON_KEY` as environment variables. The app expects the existing database tables and policies for `personal_transactions`, `savings_goals`, `rooms`, `room_members`, `group_expenses`, `expense_splits`, and `profiles`, plus the `join_room_by_code` RPC function. Row Level Security (RLS) must allow signed-in users to access only the records they are permitted to see.

Use only the Supabase anon/publishable key in this app. **Never put a Supabase service-role key in the website or commit your `.env` file to GitHub.**

## Deploy on Render

The included `render.yaml` configures a Python web service using Gunicorn. Connect the GitHub repository to Render, then add `SUPABASE_URL` and `SUPABASE_ANON_KEY` in the service's environment settings. `FLASK_SECRET_KEY` is generated by Render through the blueprint configuration.

## GitHub language detection

GitHub calculates language proportions from files in the repository. This ZIP contains the Python backend plus HTML and CSS. If replacing the C edition, remove the old C source/build files and upload this folder's contents to the repository root (not the enclosing folder). Keep the `templates` and `static` folders in place. GitHub should then detect Python as the primary language, although HTML/CSS are also part of the website.

## Important notes

- The HTML/CSS visual design has been carried over from the RupeeSense files supplied for this conversion.
- The app depends on the existing Supabase schema and Row Level Security policies; the ZIP cannot recreate or verify those remote database objects by itself.
- If your original Supabase table/column names differ, the corresponding queries in `app.py` will need to be adjusted.
